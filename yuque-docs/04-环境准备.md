## 从零开始配置环境

由于是轮子项目, 外部中间件只有利用到etcd,固然本项目不使用docker来部署项目

### 拉取项目

https://github.com/youngyangyang04/KamaRPC-Go

进入项目地址,拉下来项目

对应命令如下:

```bash
git clone https://github.com/youngyangyang04/KamaRPC-Go.git
cd KamaRPC-Go
```

### 安装etcd

#### Windows

windows安装etcd可以参考下面文章:
https://blog.csdn.net/skh2015java/article/details/80712214

#### Linux

使用 apt 安装:

```bash
sudo apt install etcd
```

启动etcd:

```bash
etcd
```

#### Mac

使用Homebrew 安装:

```bash
brew install etcd
```

安装完毕后进行验证:

```bash
etcd --version
```

安装成功后,若需要启动项目,每次可以输入 `etcd` 回车进行临时启动

### 启动项目客户端服务端demo

在项目主目录下, 开启3个终端,分别执行以下命令(需要先执行服务端再执行客户端):

```bash
# 终端1: 启动etcd
etcd

# 终端2: 启动服务端
go run ./cmd/server1

# 终端3: 启动客户端
go run ./cmd/client
```
