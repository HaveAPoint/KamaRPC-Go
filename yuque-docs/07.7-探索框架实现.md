## 什么是 Future?

在连接与连接池中,我们并没有对 Future 进行详细的解析,而我认为这个更适合在讲 `InvokeAsync` 函数的时候再讲,所以放到本章来讲。

当发出一个 RPC 请求的时候,服务端需要执行函数、计算结果、再返回, 这是需要时间的。所以客户端不能立刻拿到结果。

于是 `SendAsync()` 先给一个 **Future**。等服务器响应回来时,Future 再被填充结果。

我们可以阻塞等 / 带超时等 / 注册回调 / 检查是否完成。客户端层面可以自己控制它的行为,这就叫做 Future。

这与其他 RPC 框架部分不同,他们设计的是 Callback。你可以自己注册一个回调函数,当到了一定的时机,框架层面会自己帮你调用这个函数。当然两者可以混合思想进行使用。

### Future 风格 vs Callback 风格

| 风格 | 特点 |
|------|------|
| **Future** | 逻辑是线性的，代码更直观 |
| **Callback** | 逻辑被拆开，通过回调函数处理结果 |

### Future 代码解析

#### Future 结构体定义

```go
// internal/transport/future.go
type Future struct {
    done  chan struct{}
    res   []byte
    err   error
    mu    sync.Mutex
    codec codec.Codec

    onComplete func(error)
}
```

Future 中包含：
- `done`：一个 channel，用于通知调用方结果已经就绪，`close(done)` 广播唤醒所有等待者
- `res`：响应 body 的原始字节
- `err`：网络错误/超时/服务端 error
- `mu`：保护 res/err 的并发读写
- `codec`：序列化器，用于 `GetResult(out)` 时把 res 反序列化到业务结构体
- `onComplete`：完成回调（框架内部用来更新熔断统计）

#### NewFuture 函数

```go
func NewFuture() *Future {
    c, _ := codec.New(codec.JSON)
    return &Future{
        done:  make(chan struct{}),
        codec: c,
    }
}
```

创建一个新的 Future 实例，初始化 done channel 和默认 JSON codec。

#### 核心方法

```go
// Done：写入结果并通知等待方（由 readLoop 调用）
func (f *Future) Done(res []byte, err error) {
    f.mu.Lock()
    f.res = res
    f.err = err
    f.mu.Unlock()

    if f.onComplete != nil {
        f.onComplete(err)  // 回调更新熔断统计
    }
    close(f.done)  // 广播唤醒
}

// GetResult：阻塞等待 + 反序列化到业务对象
func (f *Future) GetResult(reply interface{}) error {
    <-f.done
    f.mu.Lock()
    defer f.mu.Unlock()
    if f.err != nil {
        return f.err
    }
    return f.codec.Unmarshal(f.res, reply)
}

// GetResultWithContext：带超时的结果获取（Invoke 同步调用使用）
func (f *Future) GetResultWithContext(ctx context.Context, reply interface{}) error {
    select {
    case <-f.done:
        return f.GetResult(reply)
    case <-ctx.Done():
        return ctx.Err()
    }
}

// IsDone：非阻塞检查是否完成
func (f *Future) IsDone() bool {
    select {
    case <-f.done:
        return true
    default:
        return false
    }
}

// WaitWithTimeout：带超时等待
func (f *Future) WaitWithTimeout(timeout time.Duration) ([]byte, error) {
    ctx, cancel := context.WithTimeout(context.Background(), timeout)
    defer cancel()
    return f.WaitWithContext(ctx)
}

// OnComplete：注册完成回调
func (f *Future) OnComplete(fn func(error)) {
    f.onComplete = fn
}
```

> **设计要点**：Future 用 `[]byte + codec` 而非直接传 Reply 对象，做到类型解耦与序列化可插拔。`OnComplete` 是一个天然的 hook 点，适合挂熔断成功/失败计数。
