# 7.4 服务发现

## 服务发现

在代码中, 有 `getAddr` 这个函数调用。这一步是：去注册中心查服务地址（在项目中我们使用的是 etcd 作为本项目的注册中心）。

## 注册中心的作用

我们举个例子, 如果我们不使用注册中心,那么我们在客户端可能这么写代码：

```go
// 硬编码IP地址
addr := "192.168.1.10:9090"
```

但是原先服务器部署在 `192.168.1.10` 这个 ip 上, 现在迁移到 `192.168.1.25` 这个 ip 上,此时客户端需要更改代码。尽管我们不将 ip 地址写到代码层面上,写到配置文件上, 我们也需要手动更改配置文件。这很麻烦。**这是强耦合**。

注册中心, 可以理解为一个"服务地址通讯录"。如果我们没有这个通讯录, 那么我们需要自己记住我们朋友的手机号,而且当朋友换手机号了,我们也不会知道。但是有了这个"通讯录", 朋友更换号码,可以更新这个通讯录, 此时,我们只要找到这个朋友,就能找到朋友的电话号码,从而拨打电话。

## 注册中心(etcd)代码封装讲解

在本项目中,我们使用的是 **etcd** 当作注册中心。我们在看代码前先来思考我们为什么选择 etcd？

### 1. 强一致性
etcd 使用的是 Raft 共识算法,它保证数据在多节点之间强一致、不会出现读到脏数据、不会出现脑裂（如果地址数据不一致，会发生客户端调用不存在的节点,服务状态混乱）。

### 2. 原生支持 TTL（自动过期）
如果服务崩溃：那么过期了,就可以自动删除服务端这边的 key,这叫做**自动健康检查**,etcd 原生支持,非常优雅。

### 3. 支持 Watch 机制（实时通知）
etcd 中的 Watch 机制,可以监听某个 key 前缀,当发生变化时,可以自动通知客户端。像代码中 `/kamaRPC/services/Arith/` 新增或删除实例的时候,客户端就会收到通知,此时客户端就可以做一些特定的操作比如实时更新本地缓存。

### 结构体定义

便于实现**本地缓存 + 实时同步**的服务发现系统, 本质上做了两件事：
- **服务注册**（服务端使用）
- **服务发现**（客户端使用）

即服务端调用封装好的 `Register`, 客户端调用封装好的 `Discover`。

```go
// internal/registry/registry.go

type Instance struct {
    Addr string
}

type Registry struct {
    client *clientv3.Client
    prefix string

    mu       sync.RWMutex
    services map[string]map[string]Instance // service -> addr -> Instance

    ctx    context.Context
    cancel context.CancelFunc
}
```

### NewRegistry：创建 etcd 注册中心实例

```go
func NewRegistry(endpoints []string) (*Registry, error) {
    cli, err := clientv3.New(clientv3.Config{
        Endpoints:   endpoints,
        DialTimeout: 5 * time.Second,
    })
    if err != nil {
        return nil, err
    }

    ctx, cancel := context.WithCancel(context.Background())

    return &Registry{
        client:   cli,
        prefix:   "/kamaRPC/services/",
        services: make(map[string]map[string]Instance),
        ctx:      ctx,
        cancel:   cancel,
    }, nil
}
```

### Register：服务注册（具体看注释,讲解的很详细了）

```go
func (r *Registry) Register(service string, ins Instance, ttl int64) error {
    // 1. 创建租约
    leaseResp, err := r.client.Grant(r.ctx, ttl)
    if err != nil {
        return err
    }

    // 2. 写入 key: /kamaRPC/services/{service}/{addr}
    key := fmt.Sprintf("%s%s/%s", r.prefix, service, ins.Addr)
    _, err = r.client.Put(r.ctx, key, ins.Addr, clientv3.WithLease(leaseResp.ID))
    if err != nil {
        return err
    }

    // 3. 后台自动续租
    ch, err := r.client.KeepAlive(r.ctx, leaseResp.ID)
    if err != nil {
        return err
    }
    go func() {
        for {
            _, ok := <-ch
            if !ok { return }
        }
    }()

    return nil
}
```

### Discover：服务发现及其相关函数

```go
func (r *Registry) Discover(service string) ([]Instance, error) {
    // 先查本地缓存
    r.mu.RLock()
    if _, ok := r.services[service]; ok {
        instances := r.copyInstances(service)
        r.mu.RUnlock()
        return instances, nil
    }
    r.mu.RUnlock()

    // 第一次发现，初始化
    if err := r.initService(service); err != nil {
        return nil, err
    }
    return r.copyInstances(service), nil
}

func (r *Registry) initService(service string) error {
    r.mu.Lock()
    defer r.mu.Unlock()

    if _, ok := r.services[service]; ok {
        return nil // 防止重复初始化
    }

    key := fmt.Sprintf("%s%s/", r.prefix, service)

    // 首次 Get 全量实例
    resp, err := r.client.Get(r.ctx, key, clientv3.WithPrefix())
    if err != nil { return err }

    r.services[service] = make(map[string]Instance)
    for _, kv := range resp.Kvs {
        addr := string(kv.Value)
        r.services[service][addr] = Instance{Addr: addr}
    }

    // 启动后台 watch
    go r.watch(service)
    return nil
}
```

### watch：实时监听服务变更

```go
func (r *Registry) watch(service string) {
    key := fmt.Sprintf("%s%s/", r.prefix, service)

    for {
        watchChan := r.client.Watch(r.ctx, key, clientv3.WithPrefix())
        for watchResp := range watchChan {
            for _, event := range watchResp.Events {
                switch event.Type {
                case clientv3.EventTypePut:
                    addr := string(event.Kv.Value)
                    r.mu.Lock()
                    r.services[service][addr] = Instance{Addr: addr}
                    r.mu.Unlock()
                case clientv3.EventTypeDelete:
                    deletedKey := string(event.Kv.Key)
                    addr := strings.TrimPrefix(deletedKey, r.prefix+service+"/")
                    r.mu.Lock()
                    delete(r.services[service], addr)
                    r.mu.Unlock()
                }
            }
        }
        // watch 断开后 1s 重连
        time.Sleep(time.Second)
    }
}
```
